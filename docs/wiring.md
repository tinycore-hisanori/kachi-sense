# 配線

1 チャンネル分（ch 0 は GP26、ch 1 は GP27 に同じ回路をもう 1 つ）。

```
3V3 ──┬── 10kΩ ──┬── 10kΩ ── AGND
      │          │
      │        VMID (約1.65V) ── 10µF ── AGND
      │          │
      │          ├──────────────┐
      │          │              │
      │        1MΩ          圧電素子（−側）
      │          │              │
      │          └── 圧電素子（＋側）
      │                         │
      │                       10kΩ（直列）
      │                         │
      │      ┌──────────────────┼──────────── GP26 (ADC0)
      │      │                  │
      └── BAT54S（3V3 / AGND へクランプ）  1.5nF ── AGND
```

- **VMID**：圧電素子の出力はプラスとマイナスに振れるので、ADC の中点（約 1.65 V）を基準にします。2 チャンネルで共用して構いません。
- **1 MΩ**：圧電素子に直流の通り道を作り、出力を VMID に落ち着かせます。
- **10 kΩ ＋ 1.5 nF**：エイリアシング防止のローパス（約 10 kHz）と、ADC ピンへの電流制限を兼ねます。
- **BAT54S**：強くぶつけたときに数十 V 出ることがあるので、ADC ピンを 3V3 と GND の間にクランプします。
- グラウンドは Pico の AGND（33 番ピン）に戻してください。

## 圧電素子の付け方

- 皿の裏の中心付近に、薄い両面テープか瞬間接着剤で貼ります。厚いスポンジテープは高い音を吸うので避けます。
- 皿の下に柔らかい敷物を敷くと、机やモーターの振動が入りにくくなります。
- リード線は皿の外で固定し、ハンドの動きで引っ張られないようにします。
