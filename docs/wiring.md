# 配線

> **v2（増幅あり）について**：今のおすすめは、圧電素子のあとに MCP6002 の 11 倍増幅を入れた v2 回路（[schematic_amp.png](schematic_amp.png)）です。R*b のあとにオペアンプの＋入力が入り、BAT43 はその入力の保護に回ります。オペアンプの出力 → R*e 10kΩ → C* → ADC です。以下の説明は増幅なしの v1 回路のものですが、VMID・圧電素子・バイアスの考え方は v2 でも同じです。

部品は [docs/bom.md](bom.md)（秋月電子の販売コード付き）を見てください。

![回路図](schematic.svg)

（`tools/draw_schematic.py` で生成しています。下は同じ回路のテキスト版です。）

1 チャンネル分の回路です。ch 0 は GP26、ch 1 は GP27 に、中点電圧（VMID）の分圧も含めてまったく同じ回路をもう 1 つ作ります（2 チャンネルは完全に独立）。分圧を 2 チャンネルで共用しても動きますが、同じ回路を 2 つ並べたほうが配線を間違えにくく、片方の皿の振動が VMID を通じてもう片方に漏れる心配もありません。

```
                3V3(OUT, 36番ピン)
                  │
                10kΩ
                  │
   VMID(約1.65V) ─┼──────────┬──────────────┐
                  │          │              │
                10kΩ       10μF          100kΩ
                  │          │              │
                AGND       AGND             │
                                            │
   圧電素子 7BB-27 ─ 黒(−) ─ VMID          │
                  └ 赤(＋) ─────────────────┴── 10kΩ ──┬────────── GP26 (ADC0, 31番ピン)
                                                       │
                                     BAT43(カソード→3V3) ┤
                                     BAT43(アノード→AGND)┤
                                                       │
                                                    1500pF
                                                       │
                                                     AGND (33番ピン)
```

- **VMID**：圧電素子の出力はプラスとマイナスに振れるので、ADC の中点（約 1.65 V）を基準にします。10 μF で安定させます。
- **100 kΩ**：圧電素子に直流の通り道を作り、出力を VMID に落ち着かせます。7BB-27 の静電容量 20 nF（村田の仕様値）と合わせた低域の切れ目は約 80 Hz です。豆の音（2〜6 kHz）も指の衝突（200 Hz 以下の大半）も、この上なので削りません。
- **10 kΩ ＋ 1500 pF**：エイリアシング防止のローパス（約 10 kHz）と、ADC ピンへの電流制限を兼ねます。1000 pF でも使えます（切れ目が約 16 kHz に上がるだけで、豆の音の帯域には影響しません）。
- **BAT43 × 2**：強くぶつけたときに数十 V 出ることがあるので、ADC ピンを 3V3 と GND の間にクランプします。1 本はカソードを 3V3 に、アノードを ADC ノードに。もう 1 本はカソードを ADC ノードに、アノードを AGND に。
- グラウンドは Pico の AGND（33 番ピン）に戻してください。

## 圧電素子の付け方

- 皿の裏の中心付近に、薄い両面テープか瞬間接着剤で、真鍮の面を皿に向けて貼ります。厚いスポンジテープは高い音を吸うので避けます。
- 皿の下に柔らかい敷物を敷くと、机やモーターの振動が入りにくくなります。
- リード線は皿の外で固定し、ハンドの動きで引っ張られないようにします。
